## Git & Versionamento
- **SEMPRE** que você concluir qualquer implementação, correção ou alteração no código, faça o commit com uma mensagem clara e envie **imediatamente** para o repositório remoto via `git push origin main`.
- Nunca deixe alterações pendentes no workspace após finalizar uma tarefa.
